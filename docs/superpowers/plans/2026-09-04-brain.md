# My Little Brain Implementation Plan

> Use subagent-driven-development for independent platform and scene tasks; root integrates core, API and UI.

**Goal:** Deliver a working web, Electron and Expo brain companion with OpenAI Realtime.
**Architecture:** npm-workspaces + Turbo; React shared scene, server-held API credentials, local conversation storage.
**Tech Stack:** TypeScript, React 19, Vite, Three.js, Express, ws, Electron, Expo.
**Spec:** docs/superpowers/specs/2026-09-04-brain-design.md

## Global constraints
- Root workspace is empty and its .git is a managed read-only placeholder, not an initialized repository; work in place without changing it.
- No API keys in clients, logs, artifacts or committed files.
- No future IBM-1/EEG/video implementation.

## Task 1: Foundation, core and provider (root)
- [x] Create workspace manifests, Turbo configuration, shared types and behavior tests.
- [x] Verify tests fail before implementing stable thought placement, spring physics and conversation reducer.
- [x] Implement server Realtime WebSocket relay for text and SDP endpoint for WebRTC voice; validate origins and input, redact upstream errors, load root .env.
- [x] Test validation, config and failure paths with an injected upstream.

## Task 2: Brain scene (scene agent)
- [x] Implement packages/brain with BrainScene React export accepting thoughts, activeThoughtId, thinking, paused, showThoughts and onThoughtSelect/onThoughtMove.

- [x] Validate package with typecheck and inspect rendered scene after integration.

## Task 3: Platforms (platform agent)
- [x] Implement apps/desktop Electron secure main/preload, custom chrome API, bundled local web/server launch and builder configuration.

## Task 4: Web experience (root)

## Task 6: User-directed simplification and perception
- [x] Root: main-content-centric workspace with equivalent left/right panes, twin switcher, brain canvas and single composer; thoughts and settings remain accessible.
- [x] Anatomy agent: actual template cortical and subcortical mesh assets, attribution and inside view.
